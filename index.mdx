Warp gives developers APIs and tools to accept crypto payments on EVM chains and to build, deploy and verify zero-knowledge proofs. Start with Pay with Warp to take payments, or use the Warp Platform to work with ZK circuits.

## Products

<CardGroup cols={2}>
  <Card title="Pay with Warp" icon="credit-card" href="/warp-pay">
    Hosted crypto checkout. Create a session from your server, redirect the customer, and get a webhook when the payment is verified on-chain.
  </Card>
  <Card title="ZK Proofs (Beta)" icon="shield-check" href="/zkproofs/introduction">
    Write and compile Circom circuits in the Warp Platform, deploy a Groth16 verifier to a testnet, and verify proofs on-chain or through the API.
  </Card>
  <Card title="Warp Verify (Beta)" icon="certificate" href="/warp-verify/overview">
    Issue zero-knowledge attestations for ownership, compliance and provenance, and let anyone check them with a public endpoint.
  </Card>
  <Card title="Roadmap" icon="map" href="/warp-bridge/introduction">
    Warp Bridge and the ZK Validator Network are design proposals. They are not yet available.
  </Card>
</CardGroup>

## How it fits together

- **Warp Platform** ([platform.usewarp.net](https://platform.usewarp.net)) is where you create projects, get API keys, configure webhooks and edit ZK circuits.
- **Warp API** (`https://api.usewarp.net`) is the public REST API for checkout sessions, ZK proof verification and attestation checks. See the [API reference](/api-reference/introduction).
- **Hosted checkout** (`https://checkout.usewarp.net`) is the page your customers use to connect a wallet and pay.
