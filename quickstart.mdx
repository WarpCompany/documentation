## Getting Started

Whether you're building a storefront, a SaaS product, or a dApp, Pay With Warp provides a simple REST API for accepting crypto payments. This guide uses the [Checkout API](/api-reference/checkout-api/create-payment-session) to create a payment session, send the customer to Warp's hosted checkout, and track the result.

<Note>
  Warp is under active development. Features marked **Coming Soon** are not yet available. Official SDKs are coming soon — until then, call the REST API directly with any HTTP client.
</Note>

## Before You Begin

<AccordionGroup>
  <Accordion title="Create a project and get your public key" icon="key">
    To accept payments, you'll need a project on the Warp Platform:

    1. Visit the [Warp Platform](https://platform.usewarp.net)
    2. Create an account or sign in
    3. Create an organization and a project, and configure where you want to receive funds
    4. Copy the project's **public key** (it starts with `pk_`) — you'll use it to create payment sessions

    <Warning>
      Never expose account credentials or session tokens in client-side code or public repositories. Create payment sessions from your backend so that customers cannot change the amount.
    </Warning>
  </Accordion>
  <Accordion title="Set up a test wallet" icon="wallet">
    For testing payments:

    1. Use a testnet-compatible wallet (MetaMask, WalletConnect, etc.)
    2. Add testnet networks (e.g., Ethereum Sepolia, Arbitrum Sepolia, Base Sepolia, Polygon Amoy)
    3. Fund your wallet with testnet tokens from public faucets

    <Tip>
      Warp supports both mainnet and testnet environments. Always test on testnets first.
    </Tip>
  </Accordion>
</AccordionGroup>

## Quick Integration: REST API

### Step 1: Create a Payment Session

From your backend, create a payment session for the order amount in USD:

```bash
curl -X POST https://checkout.usewarp.net/sessions \
  -H "Content-Type: application/json" \
  -d '{
    "public_key": "pk_YOUR_PROJECT_PUBLIC_KEY",
    "amount_usd": 49.99,
    "description": "Order #1234",
    "metadata": { "orderId": "1234" },
    "return_url": "https://yourstore.com/orders/1234/success",
    "cancel_url": "https://yourstore.com/orders/1234/cancel"
  }'
```

**Response:**

```json
{
  "session_id": "sess_1a2b3c4d5e6f",
  "checkout_url": "https://checkout.usewarp.net/sess_1a2b3c4d5e6f",
  "expires_at": "2026-01-15T10:15:00Z"
}
```

### Step 2: Redirect the Customer to Checkout

Send the customer to the returned `checkout_url`. The hosted checkout handles wallet connection, token and chain selection, pricing, and transaction submission. When the payment finishes, the customer is sent back to your `return_url` (or to `cancel_url` if they cancel).

### Step 3: Track Payment Status

Poll the session status from your backend:

```bash
curl https://checkout.usewarp.net/status/sess_1a2b3c4d5e6f
```

**Response:**

```json
{
  "session_id": "sess_1a2b3c4d5e6f",
  "status": "completed",
  "verification_step": "completed",
  "tx_hash": "0xabc123...",
  "verified_at": "2026-01-15T10:12:30Z",
  "completed_at": "2026-01-15T10:12:34Z"
}
```

`status` is one of `pending`, `processing`, `completed`, or `failed`. Only fulfill the order once `status` is `completed`, and always check the status from your backend rather than trusting the redirect alone.

## Quick Integration: JavaScript

The same flow in Node.js 18+ using the built-in `fetch` API:

```javascript
const CHECKOUT_API = 'https://checkout.usewarp.net';

// 1. Create a payment session (server-side)
async function createPaymentSession(order) {
  const res = await fetch(`${CHECKOUT_API}/sessions`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      public_key: process.env.WARP_PUBLIC_KEY, // pk_...
      amount_usd: order.totalUsd,
      description: `Order #${order.id}`,
      metadata: { orderId: order.id },
      return_url: `https://yourstore.com/orders/${order.id}/success`,
      cancel_url: `https://yourstore.com/orders/${order.id}/cancel`
    })
  });
  if (!res.ok) {
    throw new Error(`Failed to create session: HTTP ${res.status}`);
  }
  return res.json(); // { session_id, checkout_url, expires_at }
}

// 2. Check the session status
async function getSessionStatus(sessionId) {
  const res = await fetch(`${CHECKOUT_API}/status/${encodeURIComponent(sessionId)}`);
  if (!res.ok) {
    throw new Error(`Failed to fetch status: HTTP ${res.status}`);
  }
  return res.json(); // { session_id, status, verification_step, tx_hash, ... }
}

const session = await createPaymentSession({ id: '1234', totalUsd: 49.99 });
console.log('Redirect the customer to:', session.checkout_url);

const status = await getSessionStatus(session.session_id);
console.log('Payment status:', status.status);
```
