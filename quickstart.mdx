This guide takes you from a new Warp project to a completed test payment. You create a checkout session from your server, send the customer to the hosted checkout page, and fulfill the order when Warp sends a `payment.completed` webhook.

## Prerequisites

- A [Warp Platform](https://platform.usewarp.net) account with a project, and a receiving address configured for testnet payments.
- Your project's **test secret key** (`sk_test_...`). Secret keys are shown only once, when you create the project or rotate the key — store it in your server's environment, for example as `WARP_SECRET_KEY`.
- A wallet such as MetaMask or any WalletConnect-compatible wallet, funded with testnet ETH or testnet USDC on a [supported testnet](/warp-pay#supported-networks-and-tokens) such as Sepolia or Base Sepolia.

<Warning>
  Secret keys can create sessions and read your payments. Use them only on your server. Never put a secret key in browser code, a mobile app or a public repository.
</Warning>

## Steps

<Steps>
  <Step title="Create a checkout session">
    From your backend, create a session for the order amount in USD. Because you're using an `sk_test_` key, the session is a testnet session.

    <CodeGroup>

    ```bash cURL
    curl https://api.usewarp.net/v1/checkout/sessions \
      -H "Authorization: Bearer $WARP_SECRET_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "amount_usd": 49.99,
        "description": "Order #1234",
        "metadata": { "order_id": "1234" },
        "return_url": "https://example.com/orders/1234",
        "cancel_url": "https://example.com/cart"
      }'
    ```

    ```javascript Node.js
    const res = await fetch('https://api.usewarp.net/v1/checkout/sessions', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${process.env.WARP_SECRET_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        amount_usd: 49.99,
        description: 'Order #1234',
        metadata: { order_id: '1234' },
        return_url: 'https://example.com/orders/1234',
        cancel_url: 'https://example.com/cart',
      }),
    });
    if (!res.ok) {
      const { error } = await res.json();
      throw new Error(`${error.code}: ${error.message}`);
    }
    const session = await res.json();
    ```

    ```python Python
    import os
    import requests

    res = requests.post(
        "https://api.usewarp.net/v1/checkout/sessions",
        headers={"Authorization": f"Bearer {os.environ['WARP_SECRET_KEY']}"},
        json={
            "amount_usd": 49.99,
            "description": "Order #1234",
            "metadata": {"order_id": "1234"},
            "return_url": "https://example.com/orders/1234",
            "cancel_url": "https://example.com/cart",
        },
        timeout=10,
    )
    res.raise_for_status()
    session = res.json()
    ```

    </CodeGroup>

    The response is the new session:

    ```json
    {
      "id": "ps_8f14e45fceea167a5a36dedd4bea2543",
      "object": "checkout.session",
      "amount_usd": "49.99",
      "currency": "USD",
      "description": "Order #1234",
      "metadata": { "order_id": "1234" },
      "status": "pending",
      "network": "testnet",
      "return_url": "https://example.com/orders/1234",
      "cancel_url": "https://example.com/cart",
      "expires_at": "2026-10-14T12:30:00.000Z",
      "created_at": "2026-10-14T12:00:00.000Z",
      "checkout_url": "https://checkout.usewarp.net/session/ps_8f14e45fceea167a5a36dedd4bea2543"
    }
    ```

    Save the session `id` with your order. Sessions expire 30 minutes after they're created.
  </Step>
  <Step title="Redirect the customer to checkout">
    Send the customer to `checkout_url`. The hosted page lets them connect a wallet, choose a supported chain and token, and pay. Warp then verifies the transaction on-chain.

    - On the payment success page, a **Back to merchant** button returns the customer to your `return_url`.
    - On the checkout page, a **Cancel and return** link sends the customer to your `cancel_url`.

    A redirect to `return_url` is not proof of payment. Confirm the payment with a webhook or by retrieving the session.
  </Step>
  <Step title="Handle the webhook">
    In the Warp Platform, set your project's webhook URL and copy its signing secret into `WARP_WEBHOOK_SECRET`. Warp sends `payment.completed` when the payment is verified. Verify the signature, then fulfill the order:

    ```javascript Node.js (Express)
    import express from 'express';
    import { verifyWarpSignature } from './warp-webhooks.js'; // see the Webhooks guide

    const app = express();

    app.post('/webhooks/warp', express.raw({ type: 'application/json' }), async (req, res) => {
      if (!verifyWarpSignature(req.body, req.get('Warp-Signature'), process.env.WARP_WEBHOOK_SECRET)) {
        return res.status(400).send('Invalid signature');
      }
      const event = JSON.parse(req.body.toString('utf8'));
      if (event.type === 'payment.completed') {
        await fulfillOrder(event.data.object.metadata.order_id); // your own logic
      }
      res.sendStatus(200);
    });
    ```

    The [Webhooks](/warp-pay/webhooks) guide has the full signature verification code for Node.js and Python.
  </Step>
  <Step title="Test the payment">
    Open the `checkout_url`, pay with your testnet wallet, and wait for the confirmation. Then check the session from your server:

    ```bash
    curl https://api.usewarp.net/v1/checkout/sessions/ps_8f14e45fceea167a5a36dedd4bea2543 \
      -H "Authorization: Bearer $WARP_SECRET_KEY"
    ```

    `status` is `completed` and the `payment` object shows the chain, token, transaction hash and confirmations.
  </Step>
  <Step title="Go live">
    Replace `sk_test_...` with your live secret key (`sk_live_...`) and make sure your project has a mainnet receiving address. Sessions created with a live key are mainnet sessions — there is no separate base URL or `network` parameter.
  </Step>
</Steps>
