## Warp Ecosystem Overview

Warp is building a unified infrastructure layer designed to make multi-chain crypto interactions feel seamless, private, and secure. Our product suite targets the biggest pain points in modern DeFi: fragmentation, slow settlement, privacy gaps, and developer complexity.

<Note>
  Warp is under active development. Features marked **Coming Soon**, **Planned**, or **Roadmap** are not yet available, and their descriptions reflect design goals rather than current behavior.
</Note>

Each product in the Warp ecosystem can be used independently — but together, they form a powerful foundation for building next-generation cross-chain applications.

---

## Warp Bridge

### Fast, No-KYC Cross-Chain Transfers

Warp Bridge is a cross-chain transfer protocol designed to move assets between blockchains quickly, without relying on wrapped tokens, custodial bridges, or large shared liquidity pools.

**Core Features:**

- **Fast Settlement** — Solvers deliver funds from their own liquidity, so transfers are designed to complete in seconds rather than minutes or hours
- **No KYC Required** — Connect your wallet and go — no accounts, no sign-ups
- **Solver-Based Liquidity** — Permissionless market makers compete to fulfill orders, driving competitive pricing
- **Progressive Privacy** _(Roadmap)_ — Designed so that, as network activity grows, individual transfers become harder to link
- **Native Token Support** — Avoid unnecessary wrapped assets wherever possible
- **Order + Call Execution** _(Planned)_ — Trigger actions on destination chains automatically (stake, swap, deposit, etc.)

**Use Cases:**

- Cross-chain arbitrage and trading
- Multi-chain DeFi portfolio management
- Fast liquidity routing for dApps
- Trust-minimized cross-chain settlements

## Pay With Warp

### Universal Crypto Checkout for Merchants

Pay With Warp is a flexible payment solution that allows customers to pay using any token on any supported blockchain — while merchants receive the asset they choose.

**Core Features:**

- **Hosted Checkout** — Create a payment session with the [Checkout API](/api-reference/checkout-api/create-payment-session) and redirect customers to a hosted checkout page
- **Multi-Chain Payments** — Accept payments across supported networks
- **Any Token Support** — Customers pay with the supported asset they already hold
- **Automatic Conversion** _(Roadmap)_ — Warp handles routing, swapping, and settlement behind the scenes
- **Instant Confirmation** _(Roadmap)_ — Zero-knowledge proofs are intended to enable near-real-time payment verification
- **Privacy Routing** _(Roadmap)_ — Payments are planned to flow through privacy-preserving channels, designed to be harder to link on-chain
- **Crypto-to-Fiat** _(Coming Soon)_ — Option for merchants to receive traditional currency payouts

**Use Cases:**

- E-commerce checkout integration
- SaaS subscription payments
- NFT marketplace settlements
- Digital goods and services
- Cross-border payments

## ZK Proofs as a Service

### Deploy Privacy-Preserving Smart Contracts Without Writing Solidity _(Beta)_

Warp's Zero-Knowledge Proofs as a Service (ZKPaaS) is designed to let developers build and deploy ZK-powered applications through the Warp Platform and API — no cryptography expertise required.

**Features:**

- **Platform and API Access** — Create, compile, verify, and deploy proofs from the [Warp Platform](https://platform.usewarp.net) or the [API](/api-reference/zk-proofs/list-zk-proofs)
- **Circom Support** — Write and compile your own Circom circuits
- **Pre-Built Circuits** _(Planned)_ — Common use cases (payments, identity, voting) ready to use
- **Cross-Chain Verification** _(Planned)_ — Proofs verifiable on additional supported blockchains
- **Privacy by Design** — Shield sensitive data while maintaining verifiable correctness

**Target Use Cases:**

- Private payment verification
- Anonymous voting systems
- Confidential identity verification
- Shielded DeFi interactions
- Verifiable computation proofs

## ZK Validator Network

### Decentralized Infrastructure for Proof Verification and Settlement _(Coming Soon)_

The ZK Validator Network is planned as the cryptographic backbone for fast settlement, privacy routing, and trust-minimized cross-chain communication across the Warp ecosystem.

**Planned Features:**

- **Decentralized Proof Verification** — Validators verify ZK proofs and settle cross-chain orders
- **Staking and Rewards** — Network participants earn fees for providing computational power
- **Fast Verification** — Designed to verify proofs quickly, reducing reliance on long block-confirmation windows
- **Slashing** — Validators are economically incentivized to behave honestly
- **Multi-Chain Support** — Validators monitor and settle transactions across supported chains

**Target Use Cases:**

- Participate as a validator to earn network fees
- Support fast settlement for Warp Bridge transfers
- Enable privacy-preserving payment routing
- Support trust-minimized cross-chain messaging
