# **DELETE /v1/transfer/{transferId}**

Cancel a transfer that is in `pending` or `confirming` status. Once a transfer reaches `executing` status, it cannot be cancelled.

## **Request**

### **Headers**

```
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### **Path Parameters**

| Parameter | Type | Description |
|-----------|------|-------------|
| `transferId` | string | Transfer identifier to cancel |

### **Body Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `reason` | string | No | Optional cancellation reason for tracking |

### **Example Request**

```bash
curl -X DELETE "https://api.usewarp.net/v1/transfer/transfer_9x8y7z6w5v4u" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "reason": "User requested cancellation"
  }'
```

## **Response**

### **Success Response (200)**

```json
{
  "success": true,
  "data": {
    "transferId": "transfer_9x8y7z6w5v4u",
    "status": "cancelled",
    "cancelledAt": "2025-12-13T10:12:00Z",
    "refundTransaction": {
      "chainId": 1,
      "hash": "0x789abc456def...",
      "explorerUrl": "https://etherscan.io/tx/0x789abc456def..."
    },
    "refundAmount": "100000000",
    "refundToken": "USDC"
  },
  "timestamp": "2025-12-13T10:12:00Z"
}
```

### **Field Descriptions**

- `status` — Will be set to `cancelled`
- `cancelledAt` — Timestamp when cancellation was processed
- `refundTransaction` — On-chain transaction returning locked funds
- `refundAmount` — Amount returned to user (may be less gas fees)

### **Error Response (400) - Already Executing**

```json
{
  "success": false,
  "error": {
    "code": "CANNOT_CANCEL",
    "message": "Transfer cannot be cancelled because it is already being executed",
    "details": {
      "transferId": "transfer_9x8y7z6w5v4u",
      "currentStatus": "executing"
    }
  },
  "timestamp": "2025-12-13T10:12:00Z"
}
```

### **Error Response (404) - Not Found**

```json
{
  "success": false,
  "error": {
    "code": "TRANSFER_NOT_FOUND",
    "message": "Transfer with the specified ID does not exist",
    "details": {
      "transferId": "transfer_invalid123"
    }
  },
  "timestamp": "2025-12-13T10:12:00Z"
}
```

## **Cancellation Eligibility**

Transfers can only be cancelled when in these statuses:

- ✅ `pending` — Transfer created but not yet submitted on-chain
- ✅ `confirming` — Source transaction submitted but not confirmed
- ❌ `executing` — Solver has committed liquidity (cannot cancel)
- ❌ `completed` — Transfer already completed
- ❌ `failed` — Transfer already failed

<Warning>
  Once a solver has committed liquidity to fulfill your transfer, cancellation is no longer possible. Always check the transfer status before attempting to cancel.
</Warning>

# **POST /v1/payment**

Create a payment request for Pay With Warp checkout.

## **Request**

### **Headers**

```
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### **Body Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `amount` | string | Yes | Payment amount in USD (e.g., "99.99") |
| `currency` | string | Yes | Currency code (currently only "USD") |
| `merchantAddress` | string | Yes | Your receiving address (any supported chain) |
| `acceptedTokens` | array | No | Allowed tokens (default: all supported) |
| `acceptedChains` | array | No | Allowed chains (default: all supported) |
| `orderId` | string | No | Your internal order identifier |
| `metadata` | object | No | Additional data for tracking |
| `redirectUrl` | string | No | URL to redirect after payment |
| `webhookUrl` | string | No | URL to receive payment notifications |

### **Example Request**

```bash
curl -X POST "https://api.usewarp.net/v1/payment" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "99.99",
    "currency": "USD",
    "merchantAddress": "0x1234567890abcdef1234567890abcdef12345678",
    "acceptedTokens": ["USDC", "USDT", "ETH"],
    "acceptedChains": ["ethereum", "arbitrum", "polygon"],
    "orderId": "order_12345",
    "metadata": {
      "customerEmail": "customer@example.com",
      "productName": "Premium Subscription"
    },
    "redirectUrl": "https://yourstore.com/payment/success",
    "webhookUrl": "https://yourstore.com/webhooks/warp"
  }'
```

## **Response**

### **Success Response (201)**

```json
{
  "success": true,
  "data": {
    "paymentId": "payment_xyz789abc",
    "status": "pending",
    "amount": "99.99",
    "currency": "USD",
    "checkoutUrl": "https://checkout.warp.dev/payment_xyz789abc",
    "qrCode": "https://api.usewarp.net/v1/payment/payment_xyz789abc/qr",
    "expiresAt": "2025-12-13T11:10:00Z",
    "createdAt": "2025-12-13T10:10:00Z"
  },
  "timestamp": "2025-12-13T10:10:00Z"
}
```

### **Field Descriptions**

- `paymentId` — Unique payment identifier
- `checkoutUrl` — Hosted checkout page URL (redirect customers here)
- `qrCode` — QR code image URL for mobile payments
- `expiresAt` — Payment expiration timestamp (typically 1 hour)

<Tip>
  You can either redirect customers to the `checkoutUrl` or embed the Warp payment widget in your own checkout page using the `paymentId`.
</Tip>
