# **POST /v1/transfer**

Execute a cross-chain transfer using a previously generated quote. This endpoint initiates the transfer and returns tracking information.

## **Request**

### **Headers**

```
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### **Body Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `quoteId` | string | Yes | Quote identifier from `/quote` endpoint |
| `userAddress` | string | Yes | User's wallet address on source chain |
| `maxSlippageBps` | integer | No | Maximum acceptable slippage in basis points (default: 50) |
| `metadata` | object | No | Optional metadata for tracking purposes |

### **Example Request**

```bash
curl -X POST "https://api.usewarp.net/v1/transfer" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "quoteId": "quote_1a2b3c4d5e6f",
    "userAddress": "0x1234567890abcdef1234567890abcdef12345678",
    "maxSlippageBps": 100,
    "metadata": {
      "orderId": "order_12345",
      "customerId": "cust_67890"
    }
  }'
```

## **Response**

### **Success Response (200)**

```json
{
  "success": true,
  "data": {
    "transferId": "transfer_9x8y7z6w5v4u",
    "status": "pending",
    "sourceChain": "ethereum",
    "destinationChain": "arbitrum",
    "sourceToken": "USDC",
    "destinationToken": "USDC",
    "sourceAmount": "100000000",
    "destinationAmount": "99750000",
    "recipient": "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
    "sourceTransaction": {
      "chainId": 1,
      "hash": "0xabc123def456...",
      "confirmations": 0,
      "explorerUrl": "https://etherscan.io/tx/0xabc123def456..."
    },
    "createdAt": "2025-12-13T10:11:00Z",
    "estimatedCompletionAt": "2025-12-13T10:11:45Z"
  },
  "timestamp": "2025-12-13T10:11:00Z"
}
```

### **Field Descriptions**

- `transferId` — Unique identifier for tracking this transfer
- `status` — Current transfer status: `pending`, `confirming`, `executing`, `completed`, `failed`
- `sourceTransaction` — Details of the transaction on the source chain
- `confirmations` — Number of block confirmations received
- `estimatedCompletionAt` — Estimated completion timestamp

### **Transfer Status Flow**

1. `pending` — Transfer initiated, waiting for source transaction
2. `confirming` — Source transaction submitted, awaiting confirmations
3. `executing` — Solver fulfilling order on destination chain
4. `completed` — Transfer successfully completed
5. `failed` — Transfer failed (user can retry or cancel)

### **Error Response (400)**

```json
{
  "success": false,
  "error": {
    "code": "QUOTE_EXPIRED",
    "message": "Quote has expired. Please request a new quote.",
    "details": {
      "quoteId": "quote_1a2b3c4d5e6f",
      "expiredAt": "2025-12-13T10:10:00Z"
    }
  },
  "timestamp": "2025-12-13T10:11:00Z"
}
```

# **GET /v1/transfer/{transferId}**

Get the current status of a transfer.

## **Request**

### **Path Parameters**

| Parameter | Type | Description |
|-----------|------|-------------|
| `transferId` | string | Transfer identifier from execute endpoint |

### **Example Request**

```bash
curl -X GET "https://api.usewarp.net/v1/transfer/transfer_9x8y7z6w5v4u" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
