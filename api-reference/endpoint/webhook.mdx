# **Webhooks**

Warp sends webhook events to notify your application about transfer and payment status changes in real-time. Configure webhooks in your [Platform](https://platform.usewarp.net/webhooks).

---

## **Webhook Configuration**

### **Creating a Webhook Endpoint**

1. Go to [Platform → Webhooks](https://platform.usewarp.net/webhooks)
2. Click **Add Endpoint**
3. Enter your webhook URL (must be HTTPS)
4. Select which events to receive
5. Save and copy your webhook signing secret

<Warning>
  Store your webhook signing secret securely. You'll use it to verify that webhook requests are from Warp.
</Warning>

## **Webhook Events**

### **Transfer Events**

| Event | Description |
|-------|-------------|
| `transfer.created` | Transfer initiated |
| `transfer.pending` | Transfer awaiting confirmations |
| `transfer.executing` | Solver fulfilling the transfer |
| `transfer.completed` | Transfer successfully completed |
| `transfer.failed` | Transfer failed |
| `transfer.cancelled` | Transfer cancelled by user |

### **Payment Events**

| Event | Description |
|-------|-------------|
| `payment.created` | Payment request created |
| `payment.pending` | Customer initiated payment |
| `payment.completed` | Payment confirmed and settled |
| `payment.failed` | Payment failed |
| `payment.expired` | Payment request expired |

```json

  }
}
```

## **Verifying Webhook Signatures**

Every webhook request includes an `X-Warp-Signature` header. Always verify this signature to ensure the request is from Warp.

### **Node.js Example**

```javascript
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secret) {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
  
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
}

// Express.js handler
app.post('/webhooks/warp', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['x-warp-signature'];
  const payload = req.body.toString();
  
  if (!verifyWebhookSignature(payload, signature, process.env.WARP_WEBHOOK_SECRET)) {
    return res.status(401).send('Invalid signature');
  }
  
  const event = JSON.parse(payload);
  
  // Process the event
  handleWebhookEvent(event);
  
  res.json({ received: true });
});
```

### **Python Example**

```python
import hmac
import hashlib

def verify_webhook_signature(payload: str, signature: str, secret: str) -> bool:
    expected_signature = hmac.new(
        secret.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()
    
    return hmac.compare_digest(signature, expected_signature)

# Flask handler
@app.route('/webhooks/warp', methods=['POST'])
def warp_webhook():
    signature = request.headers.get('X-Warp-Signature')
    payload = request.data.decode()
    
    if not verify_webhook_signature(payload, signature, os.environ['WARP_WEBHOOK_SECRET']):
        return jsonify({'error': 'Invalid signature'}), 401
    
    event = request.json
    
    # Process the event
    handle_webhook_event(event)
    
    return jsonify({'received': True})
```

## **Best Practices**

<AccordionGroup>
  <Accordion title="Return 200 OK quickly">
    Respond with a `200 OK` status within 5 seconds. Process webhook events asynchronously to avoid timeouts.
  </Accordion>
  
  <Accordion title="Handle duplicate events">
    Warp may send the same event multiple times. Use the event `id` to deduplicate events in your database.
  </Accordion>
  
  <Accordion title="Monitor webhook failures">
    If your endpoint returns errors repeatedly, Warp will disable it after 100 consecutive failures. Monitor your webhook endpoint health.
  </Accordion>
  
  <Accordion title="Use HTTPS only">
    Webhook endpoints must use HTTPS. HTTP endpoints are rejected for security reasons.
  </Accordion>
</AccordionGroup>

## **Testing Webhooks**

### **Using the Dashboard**

You can send test webhook events from the [Platform](https://platform.usewarp.net/webhooks):

1. Select your webhook endpoint
2. Click **Send Test Event**
3. Choose an event type
4. View the request and response

### **Local Development**

For local testing, use a tool like [ngrok](https://ngrok.com/) to expose your local server:

```bash
ngrok http 3000
```

Then configure your webhook URL to the ngrok URL (e.g., `https://abc123.ngrok.io/webhooks/warp`).

## **Webhook Retry Policy**

If your endpoint doesn't respond with a `2xx` status code, Warp will retry the webhook:

- 1st retry: after 5 seconds
- 2nd retry: after 30 seconds
- 3rd retry: after 5 minutes
- 4th retry: after 30 minutes
- 5th retry: after 2 hours

After 5 failed attempts, the webhook is marked as failed. You can manually retry failed webhooks in the Platform.
