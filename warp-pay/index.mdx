Pay with Warp is a hosted crypto checkout. Your server creates a checkout session with a secret key, the customer pays on Warp's checkout page, and Warp verifies the transaction on-chain and notifies you with a webhook.

## How it works

<Steps>
  <Step title="Create a session on your server">
    Call [Create a checkout session](/api-reference/checkout-sessions/create) with your secret key and the amount in USD. Sessions can only be created server-side — there are no publishable-key or link-based sessions.
  </Step>
  <Step title="Redirect the customer">
    Send the customer to the session's `checkout_url`. They connect MetaMask or any WalletConnect-compatible wallet, choose a supported chain and token, and pay. The checkout quotes an exact token amount for your USD price, valid for 15 minutes. Stablecoins (USDC, USDT, DAI) are priced at $1. Each quote includes a unique offset of less than one cent that ties the payment to the session, so the customer must send exactly the amount shown.
  </Step>
  <Step title="Warp verifies the payment">
    Warp checks the transaction on-chain: the chain, recipient address, token contract, exact amount, that it was mined after the session was created and before the quote expired, and the number of confirmations. Underpaid, overpaid and late payments fail with a reason.
  </Step>
  <Step title="You get notified">
    Warp sends a `payment.completed` [webhook](/warp-pay/webhooks). You can also [retrieve the session](/api-reference/checkout-sessions/retrieve) at any time.
  </Step>
</Steps>

<Info>
  There is no conversion. You receive the token the customer paid with, at the receiving address configured for your project in the Warp Platform.
</Info>

## Test and live mode

Each project has a test and a live secret key. The key you use decides the network — there is no separate base URL.

| Key | Session `network` | Chains offered at checkout |
| --- | --- | --- |
| `sk_test_...` | `testnet` | Sepolia, Polygon Amoy, Base Sepolia, Arbitrum Sepolia, Optimism Sepolia |
| `sk_live_...` | `mainnet` | Ethereum, Polygon, Base, Arbitrum, Optimism |

Secret keys are shown once, when you create the project or rotate the key. Keep them on your server.

## Supported networks and tokens

Pay with Warp supports EVM chains only.

| Network | Mainnet tokens | Testnet | Testnet tokens | Confirmations (mainnet / testnet) |
| --- | --- | --- | --- | --- |
| Ethereum | ETH, USDC, USDT, DAI | Sepolia | ETH, USDC | 12 / 1 |
| Polygon | POL (shown as MATIC), USDC, USDT, DAI | Polygon Amoy | POL, USDC | 64 / 1 |
| Base | ETH, USDC | Base Sepolia | ETH, USDC | 3 / 1 |
| Arbitrum | ETH, USDC, USDT, DAI | Arbitrum Sepolia | ETH, USDC | 3 / 1 |
| Optimism | ETH, USDC, USDT, DAI | Optimism Sepolia | ETH, USDC | 3 / 1 |

Testnet USDC is Circle's testnet USDC. Payments from smart contract wallets (such as Safe) are supported for ERC-20 tokens.

## Session lifecycle

| Status | Meaning |
| --- | --- |
| `pending` | Waiting for the customer to pay. |
| `processing` | A transaction was submitted and Warp is verifying it. |
| `completed` | The payment was verified. Fulfill the order. |
| `failed` | The transaction did not pass verification. |
| `expired` | No payment within 30 minutes of creation. |

`completed`, `failed` and `expired` each trigger a webhook: `payment.completed`, `payment.failed` and `payment.expired`.

The two URLs you can pass when creating a session control navigation only:

- `return_url` — where the **Back to merchant** button on the payment success page sends the customer.
- `cancel_url` — where the **Cancel and return** link on the checkout page sends the customer.

Neither redirect proves a payment. Rely on the webhook or the session `status`.

## Example

<CodeGroup>

```bash cURL
curl https://api.usewarp.net/v1/checkout/sessions \
  -H "Authorization: Bearer $WARP_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "amount_usd": 25.00, "description": "Pro plan", "metadata": { "customer_id": "cus_42" } }'
```

```javascript Node.js
const res = await fetch('https://api.usewarp.net/v1/checkout/sessions', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.WARP_SECRET_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ amount_usd: 25.0, description: 'Pro plan', metadata: { customer_id: 'cus_42' } }),
});
const { checkout_url } = await res.json();
```

```python Python
import os
import requests

res = requests.post(
    "https://api.usewarp.net/v1/checkout/sessions",
    headers={"Authorization": f"Bearer {os.environ['WARP_SECRET_KEY']}"},
    json={"amount_usd": 25.00, "description": "Pro plan", "metadata": {"customer_id": "cus_42"}},
    timeout=10,
)
checkout_url = res.json()["checkout_url"]
```
