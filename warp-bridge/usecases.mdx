## Integration Overview

Warp Bridge is designed to offer several integration paths depending on your product’s needs. Whether you’re building a wallet, dApp, exchange, or backend service, you will be able to integrate Warp Bridge through our **API**, **widget**, or **smart contracts**.

<Note>
  The integration paths below are **Coming Soon**. Warp Bridge is under active development, and details may change before launch.
</Note>

Below is a streamlined overview of each option.

## Warp Bridge API

**Recommended for most production integrations**

The API is designed to be the most flexible way to add cross-chain transfers. It abstracts routing, pricing, execution, and multi-chain infrastructure so you can focus on user experience.

With simple REST endpoints, you will be able to quote transfers, submit them, track status, and manage lifecycle events.

<Card title="Best for teams that need:" icon="code" href="/quickstart">
  - Full control over UI/UX
  - Custom workflows or automation
  - Backend or mobile app integration
  - A robust, scalable integration method

  **Ideal for:** Wallets, swap aggregators, trading bots, DeFi platforms.
</Card>

## Warp Bridge Widget

**Best for fast integration and deployment**

The widget is designed to let you add cross-chain transfers to any website or dApp in minutes, as a customizable plug-and-play component that works via iframe or JS snippet.

<Card title="Best for teams that need:" icon="window" href="/quickstart#embedded-widget-coming-soon">
  - Fastest time-to-market
  - Minimal engineering work
  - A ready-made UI component
  - Easy integration in dashboards or WebViews

  **Ideal for:** Token swap pages, dashboards, portfolio tools, prototypes.
</Card>

## Smart Contract Integration

**Best for trust-minimized, on-chain DeFi integrations**

For protocols that need full decentralization, Warp Bridge is designed to offer on-chain contract hooks. Developers will be able to interact directly with the bridge contracts to initiate or fulfill cross-chain transfers.

<Card title="Best for teams that need:" icon="file-contract" href="/warp-bridge/protocol">
  - Fully on-chain, trust-minimized execution
  - Protocol-level features (DEXs, aggregators, solver networks)
  - Deterministic and verifiable cross-chain behavior

  **Ideal for:** DEXs, liquidity networks, solver systems, automated execution engines.
</Card>
