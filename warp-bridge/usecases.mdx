<Note>
  **Roadmap.** Warp Bridge is a design proposal and is not yet available. This page describes planned behavior, which may change.
</Note>

Warp Bridge is planned to offer three integration paths. Each would suit a different kind of product.

## Bridge API

A REST API for quoting transfers, submitting them and tracking their status. It would suit teams that want full control over the UI — wallets, swap aggregators, trading bots and backend services.

## Bridge widget

An embeddable component, added with an iframe or a script tag, that handles wallet connection, quotes and execution. It would suit teams that want cross-chain transfers with little engineering work — dashboards, token pages and prototypes.

## Contract integration

Direct calls to the WarpSource and WarpDestination contracts for protocols that need fully on-chain execution — DEXs, liquidity networks and solver systems. See [Protocol design](/warp-bridge/protocol).
