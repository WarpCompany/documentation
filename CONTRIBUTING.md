# Contributing

Thanks for helping improve the Warp docs.

1. Fork the repository and create a branch from `main`.
2. Run `mint dev` and check your changes in the local preview.
3. Run `mint broken-links` to make sure no links are broken.
4. Open a pull request with a short description of what changed and why.

Keep pages concise, use plain Markdown headings, and add any new page to `docs.json`. For larger changes, open an issue first so we can discuss the approach.
